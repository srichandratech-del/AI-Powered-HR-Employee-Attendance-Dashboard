Setup & Operations Guide

1. Dataset Schema Requirements

The dashboard accepts CSV files with the following headers:

EMP ID, NAME, DEPARTMENT, MONTH, ATTENDANCE, STATUS, LEAVE TYPE, KPI SCORE, SATISFACTION

2. Smart String Parsing Engine

  • ATTENDANCE: Automatically strips % sign to extract numeric attendance rates.
  • KPI SCORE: Extracts score before / 100 (e.g. 75 / 100 → 75).
  • SATISFACTION: Extracts numerical star rating before ★ symbol.

3. Interactive Slicers & Filtering

Use the sidebar slicers to filter by Month, Status, Leave Type, or Department. All 5 KPI cards and 5 Chart.js charts update instantly in real-time.

4. Theme & Responsiveness

Click the moon/sun icon in the top header to switch between Light and Dark mode. Charts automatically re-theme grid lines and text colors.
